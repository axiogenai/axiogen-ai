Frequently Asked Questions

Everything you need to know about AXIOGEN access and security.

What is the 5-Minute Guest Workspace?

It is a temporary, fully featured trial workspace. You can chat with base models and test voice features for 5 minutes without creating an account. The timer is persisted in localStorage so refreshes do not reset it. Once expired, you will need to Log In or Register to continue.

Is my data securely managed?

Yes. AXIOGEN operates in a client-side environment. We use anonymous Supabase session handlers and zero-logging endpoints to process requests. Your chat histories are stored strictly inside your browser's local cache (localStorage) and never logged to database servers.

How do I unlock file uploads and code compiling?

These advanced tools require secure cloud environments and premium AI completions. To prevent abuse, they are restricted to logged-in accounts. Simply Sign Up for a free profile to begin using Docs, Sheets, and AXIOGEN Code workspaces.
